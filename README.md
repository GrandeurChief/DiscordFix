> ### РЕАКЦИЯ АНТИВИРУСОВ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret необходим WinDivert — инструмент, который перехватывает и фильтрует трафик.
> Его могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов классифицирует файлы WinDivert как ПО повышенного риска или хакерские инструменты, после чего удаляет их либо переносит в карантин. Название такого обнаружения обязательно содержит `WinDivert` или выглядит как `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса или выключите обнаружение PUA — потенциально нежелательных приложений. Например, в Касперском для этого предусмотрен параметр «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы умеете аккуратно настраивать исключения, рекомендуется добавить исключение; если не уверены в своих действиях, лучше отключить обнаружение PUA.

## ⚙️Как пользоваться

1. Настройте Безопасный DNS (Secure DNS)
    * В Chrome включите «Использовать безопасный DNS» и укажите поставщика DNS, отличного от варианта «Поставщик по умолчанию»
    * В Firefox откройте «DNS через HTTPS», установите режим «Персональный», затем выберите «Выбрать провайдера/поставщика» и вручную укажите URL. Например, подойдёт `https://dns.google/dns-query`, поскольку поставщик Cloudflare может быть заблокирован
    * Windows 11 позволяет активировать Secure DNS непосредственно в параметрах системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 рекомендуется этот способ
    * Владельцам роутеров Keenetic нужно включить настройку «Транзит запросов». Если она отключена, при настройке и работе Secure DNS на компьютере могут возникнуть проблемы

2. Загрузите архив zip или rar со [страницы актуального релиза](https://github.com/GrandeurChief/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте пункт «Разблокировать». При использовании 7-Zip или PeaZip выполнять этот шаг не требуется

4. Извлеките архив в каталог, путь к которому не содержит кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск позволяет проверить конкретную стратегию. Её работоспособность определяется множеством факторов, поэтому **перебирайте разные варианты, включая ALT, FAKE и другие, пока не найдёте подходящее решение**

- [**`service.bat`**](./service.bat) — управление автозапуском и дополнительные возможности:
  - <ins>**`Install Service`** — установка выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаление из служб стратегии и WinDivert
  - **`Check Status`** — просмотр состояния обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — смена режима обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — выбор режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Эта функция полезна при тестировании ресурса, который доступен без zapret, но не работает вместе с ним.  
  В скобках показывается активный режим:
    - `none` — ни один IP не проверяется
    - `loaded` — для IP проверяется наличие в списке
    - `any` — фильтр применяется к любому IP  
  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** — замена указанного активного фейка другим файлом из каталога `bin`
  - **`Update IPSet List`** — загрузка актуальной версии списка `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений
  - **`Run Diagnostics`** — поиск распространённых причин, мешающих работе zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, если приложение внезапно перестало работать
  - **`Run Tests`** — запуск проверки работоспособности стратегий:
    - `Standard tests` — тестирование сайтов, указанных в `utils/targets.txt`
    - `DPI checkers` — проверка DPI через разных поставщиков, включая Cloudflare и Amazon


## ☑️Частые вопросы и неполадки

### При запуске скрипта `general*` ничего не происходит

- Если стратегия запускается отдельным bat-файлом, а не через service, должен открыться процесс winws.exe, отвечающий за обход; его значок отображается на панели задач.  
Если этого не случилось, изучите [#522](https://github.com/GrandeurChief/zapret-discord-youtube/issues/522)

### Не удаётся подобрать стратегию
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- После этого перезагрузите компьютер

### Веб-версия Telegram не работает
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого файла в Блокноте
  - В появившемся каталоге откройте файл `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленный аналогичный блок
  - Сохраните файл и снова проверьте подключение. Если результата нет, удостоверьтесь, что изменения в `hosts` действительно сохранились.

#### Результат не гарантируется. Если способ не сработал, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/GrandeurChief/tg-ws-proxy) либо любой публичный прокси.

### Обход перестал работать или не запускается

> [!IMPORTANT]
> **Любая стратегия со временем может утратить работоспособность.**
> Даже если определённый вариант работает сейчас, позднее его могут обнаружить, и он перестанет помогать.
> В этом репозитории собрано много стратегий обхода. Когда ни одна из готовых конфигураций не подходит, создайте новую на основе одной из имеющихся, изменив её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Выполните `service.bat` -> `Run Diagnostics` и убедитесь, что ошибок нет

- Проверьте наличие адреса нужного ресурса в перечнях доменов или IP

- Переключитесь на другие стратегии, в том числе **`ALT`**, **`FAKE`** и остальные

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация приведена в [#765](https://github.com/GrandeurChief/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить программу?
- Сначала сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`, устраните найденные ошибки и в конце выберите Y
- Удалите каталог с zapret
- Загрузите свежую версию `zapret-discord-youtube-...` [со страницы релизов](https://github.com/GrandeurChief/zapret-discord-youtube/releases)
- Щёлкните архив правой кнопкой мыши и откройте свойства. Если справа внизу есть флажок «Разблокировать», установите его, нажмите «Применить», затем «ОК»
- Распакуйте содержимое в новый каталог в корне диска; в пути не должно быть пробелов и специальных символов
- Поочерёдно запускайте разные скрипты `general`, то есть стратегии, и проверяйте доступ к интернет-ресурсам. Если они недоступны, закройте программу через значок замка на панели задач и испытайте другой вариант
- Обнаружив рабочую стратегию, добавьте её в автозапуск: `service.bat` -> `Install Service` -> выберите нужный вариант

### Игра или приложение недоступны при включённом zapret

- Убедитесь, что в `service.bat` для `Game Filter` задано **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения способны повлиять на доступность ресурсов, которые вы не планировали фильтровать.

### Античит обнаруживает WinDivert

- Следуйте инструкции: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert остаётся в системе

1. Откройте командную строку Windows через Win+R и `cmd`, затем определите название службы:

```cmd
driverquery | find "Divert"
```

2. Остановите найденную службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fкак-пользоваться)
- Выключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если прежняя раньше работала, а затем перестала.
- Дополнительные сведения есть в [#251](https://github.com/GrandeurChief/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Удостоверьтесь, что [Secure DNS](#%EF%B8%8Fкак-пользоваться) настроен
- Сначала желательно определить стратегию, с которой открывается сайт YouTube, и запустить именно её
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord
- Снова откройте приложение Discord и проверьте, помогла ли очистка
- Перейдите в браузере на https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если Discord недоступен и в браузере, ещё раз переберите все стратегии. Иногда YouTube работает с определённой стратегией, а Discord — нет
- Другие рекомендации собраны в [#252](https://github.com/GrandeurChief/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь приложением [tg-ws-proxy](https://github.com/GrandeurChief/tg-ws-proxy)
- Другой вариант — бесплатные публичные MTProto-прокси из интернета

### Игры не работают

Игр много, поэтому проверить и исправить работу каждой из них невозможно.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat`, затем включите `Game Filter`
- если проблема сохранится, дополнительно активируйте параметр `ipset any`

Учтите, что режим `ipset any` мешает открытию многих сайтов, поэтому не оставляйте его включённым постоянно. Чтобы избежать этого, определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если перечисленные действия не помогли, создайте тему в разделе [Discussions](https://github.com/GrandeurChief/zapret-discord-youtube/discussions), а не в issues, и дождитесь рекомендаций других игроков.

## 🗒️Как добавить адреса других ресурсов

Расширяйте перечень адресов для обхода через следующие файлы:
- **`list-general-user.txt`** — домены; их поддомены учитываются автоматически
- **`list-exclude-user.txt`** — исключения доменов, например когда IP сети присутствует в `ipset-all.txt`, но отдельный домен из неё фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Файлы с именами **`*-user.txt`** будут созданы автоматически после первого запуска `zapret` или `service.bat`
